Типы и топологии сетей

Компьютерная сеть объединяет устройства для обмена данными и совместного использования ресурсов. По масштабу выделяют локальные сети (LAN), городские и корпоративные сети (MAN), а также глобальные сети (WAN), к которым относится интернет.

Топология описывает физическую или логическую схему соединения узлов. В топологии «звезда» все устройства подключены к центральному коммутатору, что упрощает управление. «Кольцо» и «шина» сегодня используются реже, но важны для понимания эволюции сетей.

Выбор топологии влияет на стоимость инфраструктуры, отказоустойчивость и удобство масштабирования. В современных организациях часто применяется гибридная схема: сочетание проводной сети, Wi-Fi сегментов и виртуальных сетей для разделения трафика.

  • Узел сети — любое подключенное устройство: ПК, сервер, принтер, маршрутизатор.
  • Пропускная способность — объем данных, передаваемый за единицу времени.
  • Задержка (latency) — время, за которое пакет доходит от отправителя к получателю.
  • Отказоустойчивость — способность сети продолжать работу при сбоях.

Протоколы и модель OSI

Протокол — это набор формальных правил, по которым устройства обмениваются сообщениями: как устанавливается соединение, в каком формате передаются данные и как обрабатываются ошибки. Без общих протоколов устройства разных производителей не могли бы взаимодействовать.

Модель OSI разделяет процесс сетевого обмена на 7 уровней: физический, канальный, сетевой, транспортный, сеансовый, представления и прикладной. Такое разделение упрощает проектирование и диагностику: проблемы можно локализовать по уровням.

На практике интернет работает на стеке TCP/IP. Протокол IP отвечает за адресацию и маршрутизацию, TCP обеспечивает надежную доставку с контролем порядка, а UDP используется там, где важнее скорость и допустимы потери (например, в потоковом аудио/видео и играх).

Протокол Назначение Пример применения
IP Адресация и маршрутизация пакетов Доставка пакетов между сетями
TCP Надежное соединение и контроль порядка Веб-страницы, почта, загрузка файлов
UDP Быстрая передача без подтверждений Видеозвонки, стриминг, онлайн-игры

Интернет и веб-технологии

Интернет — это глобальная сеть сетей, основанная на IP-маршрутизации. Веб является одним из сервисов интернета и строится на модели клиент-сервер: браузер отправляет запрос, сервер возвращает ответ с данными страницы.

Ключевые веб-технологии: HTML (структура документа), CSS (оформление), JavaScript (интерактивность), HTTP/HTTPS (протокол обмена). За безопасность передачи отвечает TLS в составе HTTPS: он шифрует трафик между клиентом и сервером.

Каждое устройство в сети имеет IP-адрес. Доменные имена, такие как `example.com`, преобразуются в IP через DNS. После этого браузер устанавливает соединение, отправляет HTTP-запрос и получает ресурсы сайта: HTML, стили, скрипты, изображения. Современные приложения активно используют API, кэширование и CDN для ускорения загрузки и стабильной работы при высокой нагрузке.

  • DNS — система, преобразующая доменное имя в IP-адрес.
  • HTTPS — защищенный HTTP-трафик с шифрованием TLS.
  • API — интерфейс обмена данными между программами и сервисами.
  • CDN — сеть распределенных серверов для быстрой выдачи контента.
